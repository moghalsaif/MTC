<analysis>**original_problem_statement:** The user wants to build an Equipment Tracker Dashboard for a virtual production studio to manage gear for shoots.

**PRODUCT REQUIREMENTS:**
-   **Core Purpose:** Track equipment status (in studio vs. out on shoot), check availability for upcoming shoots, and simplify the checkout/check-in process.
-   **Core Workflows:**
    1.  **Mark Out:** From a master equipment list, a user can select an item, specify the quantity, the project it's for, and the expected return date. This updates the item's available quantity.
    2.  **Mark In:** From a list of items currently out, a user can mark items as returned, note their condition, and report any damage or loss. The system should automatically create issue/lost item tickets if needed.
-   **Required Dashboards/Views:**
    -   **Main Dashboard:** An overview of items out, overdue gear, active projects, low stock items, and open issues.
    -   **Inventory View:** A filterable and searchable list of all equipment with their current quantities (available/out).
    -   **Items Currently Out View:** A list of all checked-out gear, grouped by project, with a Mark In option.
    -   **Project View:** A detailed view for each project, showing reserved and checked-out items.
    -   **Issues, Lost Items, and Maintenance Dashboards:** To track equipment problems, missing items, and repairs.
-   **Key Logic:**
    -   Live quantity updates for all inventory movements.
    -   Automatic flagging of overdue items.
    -   No individual serial number tracking; only quantity-based.
-   **UI/UX:**
    -   Must be fast, intuitive, and mobile-friendly.
    -   Renamed to Mach Traffic Controller.
    -   UI should have an Apple-style design with rounded corners and a dark theme.
    -   Equipment names should use an F1-style technical font.
-   **Features Added:**
    -   PDF packing list generation for projects.
    -   Packing timer to track the time it takes to pack for a shoot.
    -   Simplified Mark In process with quick-action buttons (All Good, Damaged, Missing).
    -   Project selection is required before viewing items to mark in.

**User's preferred language**: English
